# 🏫 GPIWL Website

A modern and responsive landing page created for **Government Polytechnic Institute for Women (GPIWL)**.

The project presents institutional information through a clean, organized, and user-friendly interface while providing a responsive experience across different screen sizes.

---

## 🌐 Live Demo

🔗 **[View Live Website] https://gpiwl-website.vercel.app/**

---

## ✨ Features

- Modern and clean educational website design
- Responsive layout for different screen sizes
- Well-organized institutional content
- Interactive frontend elements
- Easy-to-use navigation
- Clean typography and structured sections
- User-friendly interface

---

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout and responsive design
- **JavaScript** — Interactive functionality

## 🎯 Project Purpose

This project was developed to create a modern landing page for Government Polytechnic Institute for Women while practicing real-world frontend development using HTML, CSS, and JavaScript.

The project helped strengthen my skills in responsive layouts, interface design, content organization, and frontend interactivity.

The website is designed to adapt across desktop, tablet, and mobile screen sizes, providing a consistent and accessible browsing experience.
